# Accounting Stress Test Scenarios

## Purpose

Before implementation, the accounting engine must survive real-world failures, fraud attempts, and unusual farm situations.

---

# Scenario 1: Employee Tries to Delete a Sale

Problem:

A cashier wants to hide a cash shortage by deleting yesterday's sale.

Expected System Response:

- Deletion blocked
- Audit event created
- Supervisor notification triggered

---

# Scenario 2: Fertilizer Inventory Goes Negative

Problem:

Worker records using 50 kg of fertilizer but only 20 kg exists.

Expected System Response:

- Transaction blocked
- Stock warning displayed
- Supervisor approval required for correction

---

# Scenario 3: Customer Pays Partial Invoice

Problem:

A resort owes ₱100,000 and pays only ₱40,000.

Expected System Response:

- Payment recorded
- Remaining ₱60,000 stays in Accounts Receivable
- Customer aging updated

---

# Scenario 4: Duplicate Supplier Payment

Problem:

An employee accidentally attempts to pay the same invoice twice.

Expected System Response:

- Duplicate payment detected
- Payment blocked
- Warning displayed

---

# Scenario 5: Closed Period Modification

Problem:

A user attempts to add an expense into a closed month.

Expected System Response:

- Transaction rejected
- Reopening approval workflow required

---

# Scenario 6: Typhoon Destroys Crop

Problem:

A typhoon destroys 70% of a tomato block.

Expected System Response:

- Abnormal biological loss recorded
- Asset value adjusted
- Loss reported separately from normal COGS

---

# Scenario 7: Payroll Fraud Attempt

Problem:

A supervisor increases his own salary before payroll approval.

Expected System Response:

- Permission checks triggered
- Unauthorized change blocked
- Audit alert generated

---

# Scenario 8: Cash Drawer Shortage

Problem:

Daily cash count is ₱1,000 less than ERP records.

Expected System Response:

- Variance recorded
- Investigation required
- Management approval needed for adjustment

---

# Scenario 9: Seasonal Worker Returns

Problem:

A worker returns after six months.

Expected System Response:

- Previous employee record reactivated
- Historical payroll maintained
- New employment period created

---

# Final Accounting Principle

Accounting is not only about recording profits.

It is a control system designed to answer:

- Where did the money come from?
- Where did the money go?
- Who approved the transaction?
- What assets remain?
- Which operations are profitable?
- Can the records be trusted?

PickUrVeggie ERP V3 must always prioritize accuracy, traceability, security, and auditability over convenience.
