# Audit Trail and Financial Record Lock

## Purpose

Financial information must be protected from unauthorized changes.

PickUrVeggie ERP V3 maintains a complete historical record of every financial action.

No financial event should disappear without leaving evidence.

---

## Audit Trail Coverage

The system records activity involving:

- Journal entries
- Sales invoices
- Customer payments
- Supplier payments
- Purchase transactions
- Inventory adjustments
- Payroll records
- Asset transactions
- Financial reports
- Account configuration changes

---

## Audit Record Details

Every audit entry stores:

- Unique audit ID
- Date and time
- User account
- Employee identity
- Device information
- Location (when applicable)
- Action performed
- Previous value
- New value
- Reason for change

---

## Financial Record Locking

Once a financial transaction is approved:

Status:
APPROVED

The record becomes locked.

Users cannot:

- Delete transactions
- Edit financial amounts
- Change dates
- Modify account references

---

## Correction Principle

Mistakes are corrected using adjustment transactions.

Example:

Incorrect fertilizer purchase:

Original:
₱10,000

Correct amount:
₱8,000

The ERP creates:

Adjustment:
₱2,000 reduction

The original transaction remains in history.

---

## Permission Levels

Examples:

Farm Worker:
No financial modification rights.

Operator:
Limited operational financial access.

Administrator:
Can create financial records.

Accountant:
Can create adjustments.

Owner:
Has final approval authority.

---

## Suspicious Activity Monitoring

The system may generate alerts for:

- Excessive adjustments
- Repeated failed approvals
- Large write-offs
- Backdated transaction attempts
- Unusual inventory losses

---

## Audit Principle

Trust is not created because employees are honest.

Trust is created because the system can prove what happened.

Every important financial action must be traceable.
