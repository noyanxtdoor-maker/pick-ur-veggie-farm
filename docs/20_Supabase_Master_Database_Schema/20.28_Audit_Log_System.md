# Audit Log System

Every important action is recorded.

---

## Logged Information

- User
- Date and time
- Device
- Action performed
- Previous value
- New value
- Reason for change

---

## Examples

Inventory Adjustment:

Before:
100 kg fertilizer

After:
95 kg fertilizer

Reason:
Physical count correction.

---

## Security Rules

Audit logs cannot be edited or deleted.

Only authorized users can view sensitive audit history.
