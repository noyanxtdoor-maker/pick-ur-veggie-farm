# Notifications and Messaging

The ERP provides role-based communication.

---

## System Notifications

Examples:

Inventory:

"Calcium Nitrate stock below minimum level."

Production:

"Tomato Tunnel A requires pruning today."

Accounting:

"Customer payment overdue."

Maintenance:

"Generator service due in 3 days."

---

## Internal Messaging

Users can communicate inside the ERP.

Examples:

Owner ↔ Manager

Manager ↔ Operators

Operators ↔ Workers

---

## Rules

Messages follow permission levels.

Private conversations remain private.

Operational messages can be attached to:

- Tasks
- Production events
- Inventory records
- Deliveries
