# File Attachments and Documents

The ERP supports storing evidence and documents.

---

## Supported Files

- Photos
- PDFs
- Invoices
- Receipts
- Delivery documents
- Equipment manuals
- Certificates

---

## Examples

Purchase record:

Attach supplier invoice.

Crop loss:

Attach damage photographs.

Equipment repair:

Attach repair receipts.

---

## Storage Rule

Files are linked to ERP records but do not replace the audit history.
