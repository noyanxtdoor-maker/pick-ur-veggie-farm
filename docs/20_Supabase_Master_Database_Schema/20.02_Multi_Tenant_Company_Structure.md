# Multi-Tenant Company Structure

The database supports multiple farms and organizations.

Example:

Company A
- Users
- Inventory
- Customers
- Crops
- Accounting

Company B
- Separate records

## Main Table

Companies

Fields:

- Company ID
- Company Name
- Registration Information
- Address
- Contact Details
- Subscription Status
- Created Date

Every major table will include:

company_id

for data isolation.
