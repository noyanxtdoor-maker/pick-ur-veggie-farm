# Crop Blocks and Biological Assets

Every growing area is treated as a production unit.

Examples:

- DFG Eggplant Tunnel A
- Tomato Greenhouse B
- NFT Lettuce Zone 3

---

## Crop Block Information

Contains:

- Crop Block ID
- Crop Variety
- Location
- Plant Count
- Planting Date
- Expected Harvest Date
- Expected Yield
- Current Status

---

## Cost Accumulation

Before harvest:

Costs are accumulated as Biological Assets.

Examples:

- Seeds
- Cocopeat
- Fertilizers
- Labor
- Electricity

---

## Multi-Harvest Crops

For crops like:

- Eggplant
- Tomato
- Chili

The system uses a depletion model.

Costs are gradually transferred into harvested inventory throughout the production cycle.
