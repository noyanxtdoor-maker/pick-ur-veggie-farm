# Offline Sync Queue

The ERP is designed for farms with unstable internet.

---

## Offline Operation

Users can continue:

- Recording harvests
- Using inventory
- Logging production
- Creating deliveries
- Taking photos

without internet.

---

## Sync Process

When connection returns:

Local Device
      |
      ↓
Sync Queue
      |
      ↓
Cloud Database

---

## Conflict Resolution

If two users edit the same record:

The system:

- Detects conflicts
- Preserves history
- Requests supervisor review if needed
