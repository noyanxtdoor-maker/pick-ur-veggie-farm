# Harvest Batch Traceability

Every harvest creates a unique batch.

Example:

HB-20260618-T1-EGG-01

Meaning:

HB = Harvest Batch

20260618 = Harvest Date

T1 = Tunnel 1

EGG = Eggplant

01 = Daily Sequence Number

---

## Batch Information

Stores:

- Harvest Date
- Crop Block
- Harvest Weight
- Grade
- Operator
- Shelf Life
- Storage Location

---

## Traceability Chain

Customer Sale
↓
Harvest Batch
↓
Crop Block
↓
Seed Lot
↓
Supplier Purchase

This allows complete seed-to-sale traceability.
