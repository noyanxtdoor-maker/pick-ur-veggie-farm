# Database Philosophy

PickUrVeggie ERP V3 follows enterprise ERP database principles.

## Core Rules

### 1. Multi-Tenant Design

Multiple companies can use the same application while their data remains isolated.

### 2. No Hard Deletes

Records are never permanently removed.

Use statuses:

- Active
- Inactive
- Archived
- Void

### 3. Complete Traceability

Every important action records:

- Who created it
- Who modified it
- Date and time
- Reason for change

### 4. Immutable Transactions

Historical transactions are never edited.

Corrections are performed using adjustment entries.

### 5. Financial Relationship

Every operational event should have a financial consequence:

Purchase → Inventory Asset

Consumption → Production Cost

Harvest → Finished Goods Inventory

Sale → Revenue + COGS
