# Company Calendar Event Engine

The operational calendar controls business activities.

Examples:

- Planting schedules
- Fertigation
- Harvest
- Deliveries
- Maintenance
- Meetings

---

## Calendar Features

- Day View
- Week View
- Month View
- Year View
- Crop Timeline Gantt View

---

## Smart Scheduling

The system prevents:

- Double booking workers
- Equipment conflicts
- Schedule overlaps

---

## ERP Connection

Operational events can create actions in:

- Production
- Inventory
- Labor
- Accounting
