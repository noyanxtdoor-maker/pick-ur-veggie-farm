# Production Events

All farm activities are recorded as production events.

Examples:

- Seeding
- Transplanting
- Fertigation
- Pruning
- Spraying
- Testing EC and pH
- Maintenance
- Harvest

---

## Event Records

Each event stores:

- Date and Time
- Operator
- Location
- Crop Block
- Materials Used
- Labor Time
- Notes
- Photos

---

## Cost Relationship

Events can create automatic cost allocations.

Example:

Use 5kg Calcium Nitrate.

Inventory decreases.

Crop production cost increases.
