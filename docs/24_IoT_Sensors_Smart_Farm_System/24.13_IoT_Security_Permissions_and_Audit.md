# IoT Security, Permissions and Audit

## Purpose

IoT devices are connected to business systems.

Security prevents unauthorized access, data manipulation, and malicious activities.

---

## Device Authentication

Every device receives:

- Unique Device ID
- Authentication credentials
- Registered farm location
- Approved communication rights

---

## User Permissions

Examples:

Farm Worker:

Can view environmental data.

---

Supervisor:

Can acknowledge alerts.

---

Administrator:

Can configure devices and system settings.

---

## Audit Trail

The ERP records:

- Device registrations
- Configuration changes
- Calibration records
- Alert acknowledgements
- Security events

---

## Security Monitoring

The system detects:

- Unknown devices
- Invalid login attempts
- Unusual data transmission
- Device communication failures

---

## Security Principle

A smart farm must be intelligent and protected.

Every connected device becomes part of the farm's security responsibility.
