# 10.02 — User Roles & Permissions

This document defines what each role can see, create, edit, approve, and delete.

## Core Roles
- Owner
- Co-owner
- Admin
- Accountant
- Farm Manager
- Operator
- Employee
- Driver
- Sales Staff

## Permission Categories
- View
- Create
- Edit
- Delete
- Approve
- Export
- Assign
- Lock
- Reopen

## Privacy Rules
- Personal calendars are private by default.
- Private notes belong only to the creator.
- Operational data follows role permissions.
- Sensitive financial data is restricted by role.
