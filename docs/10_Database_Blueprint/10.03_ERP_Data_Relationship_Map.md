# 10.03 — ERP Data Relationship Map

This document defines how major entities connect.

## Core Flow
Purchase Order
→ Inventory Asset
→ Inventory Consumption
→ Crop Cost
→ Crop Batch
→ Harvest Batch
→ Sale
→ Invoice
→ Payment
→ Financial Reports

## Relationship Principles
- One company can have many users.
- One farm can have many zones.
- One crop batch can create many harvest batches.
- One harvest batch can be sold in partial quantities.
- One inventory item can have many lots and movements.
- One sale can generate one or more accounting journal entries.
- One user can own many private calendar events.

## Critical Rule
Every operational action must map to a traceable ERP record.
