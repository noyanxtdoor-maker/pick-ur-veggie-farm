# 10.05 — Supabase Multi-User Sync Architecture

This document defines how PickUrVeggie ERP V3 should synchronize across tablets and devices.

## Core Model
- One central company database
- Many users
- Many devices
- Offline-first capture
- Sync when internet returns

## Sync Principles
- Local data must not disappear during outages.
- Each device needs queued transactions.
- Conflicts must be detected and resolved.
- Operational data must stay consistent across users.

## Security Principles
- Role-based access control
- Private workspace separation
- No user-to-user private data exposure
- Secure logging of sync activity

## Important Design Goal
The system must behave reliably on field tablets with unstable internet.
