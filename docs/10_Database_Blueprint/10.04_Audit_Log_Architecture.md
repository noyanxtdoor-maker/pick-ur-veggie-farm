# 10.04 — Audit Log Architecture

This document defines the permanent traceability layer for the ERP.

## Audit Log Requirements
Every important action must store:
- User
- Timestamp
- Device
- Module
- Action
- Old Value
- New Value
- Reason
- Approval Status

## Audited Actions
- Inventory adjustments
- Sales edits
- Delivery changes
- Calendar changes
- Journal corrections
- User permission changes
- Period lock changes

## Audit Principles
- No silent edits.
- No hidden deletions.
- No untraceable financial changes.
- Locked periods require approval and adjustment records.
