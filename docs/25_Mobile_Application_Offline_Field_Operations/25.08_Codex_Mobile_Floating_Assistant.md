# Codex Mobile Floating Assistant

## Purpose

Codex Farm Companion is available anywhere inside the mobile application.

Users should never need to leave their current task to ask for assistance.

---

# Floating Codex Button

A persistent Codex icon appears on all screens.

Example:

🐾 Codex

Position:

- Bottom-right corner
- Easy reach for one-handed use

---

# Context Awareness

Codex understands the user's current screen.

Example:

User is viewing:

Eggplant Tunnel A Harvest

User asks:

"How much did we harvest here last week?"

Codex understands the context and provides an answer based on permissions.

---

# Worker Assistance

Examples:

"How do I perform this task?"

"What fertilizer should I prepare?"

"Show the SOP for harvesting lettuce."

---

# Management Assistance

Examples:

"Which production area has the lowest yield?"

"Why did fertilizer cost increase?"

"What tasks are overdue?"

---

# Quick Actions

Codex can prepare:

- Task reports
- Inventory requests
- Maintenance requests
- Problem reports

Approval is required for important actions.

---

# Offline Mode

When external AI services are unavailable:

Codex can still provide:

- Stored SOPs
- Local task information
- Basic ERP intelligence

---

# Design Philosophy

Codex is not a separate application.

Codex is a companion that walks with the user throughout every farm operation.
