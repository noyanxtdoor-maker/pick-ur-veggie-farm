# Time Attendance and Work Logging

## Purpose

The mobile application allows employees to record their attendance and daily work activities directly from the field.

The system must be simple, fast, and reliable.

---

# Attendance Philosophy

Version 1 follows a trust-based attendance model.

No GPS tracking is required.

Attendance records are supported by:

- Employee accounts
- Device trust
- Time records
- Supervisor review
- Audit history

---

# Time In Workflow

Employee opens mobile app.

↓

Press:

"Time In"

↓

System records:

- Employee ID
- Date
- Time
- Device ID
- Login session

↓

Attendance record created.

---

# Time Out Workflow

Employee presses:

"Time Out"

The system records:

- End time
- Total hours worked
- Overtime hours
- Attendance status

---

# Attendance Exceptions

Examples:

Late Arrival:

Scheduled:
7:00 AM

Actual:
7:25 AM

Status:
Late

---

Early Departure:

Scheduled:
5:00 PM

Actual:
4:15 PM

Status:
Early Time Out

---

Missing Time Out:

Example:

Employee forgot to time out.

System action:

- Creates attendance warning
- Sends notification to employee
- Allows supervisor correction with reason

---

# Work Activity Logging

Employees can record:

- Harvest activities
- Fertilizer application
- Irrigation tasks
- Equipment maintenance
- Cleaning activities
- Problem reports

---

# Payroll Integration

Approved attendance data connects with:

- Working hours
- Overtime calculation
- Leave records
- Payroll computation

---

# Security Principle

Attendance records cannot be silently changed.

All corrections require:

- Authorized permission
- Reason for correction
- Audit history
