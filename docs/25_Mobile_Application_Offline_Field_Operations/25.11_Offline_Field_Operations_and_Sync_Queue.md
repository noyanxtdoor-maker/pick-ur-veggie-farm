# Offline Field Operations and Sync Queue

## Purpose

Farm activities must continue even when mobile internet is unavailable.

Every offline action is safely stored and synchronized later.

---

# Offline Workflow

Worker Action

↓

Local Mobile Database

↓

Sync Queue

↓

Internet Connection Available

↓

Synchronization Engine

↓

Supabase ERP Database

---

# Supported Offline Activities

Examples:

- Time in and time out
- Harvest recording
- Material usage recording
- Task completion
- Problem reporting
- Photo capture
- Maintenance reports

---

# Sync Queue Information

Each queued item stores:

- Record type
- User
- Date and time
- Device ID
- Current sync status
- Error messages

---

# Sync Status Levels

Pending:

Waiting for internet.

---

Synchronizing:

Currently transferring.

---

Completed:

Successfully saved to ERP.

---

Failed:

Requires review or correction.

---

# Conflict Management

If the same record is changed in two places:

The system:

- Preserves original information
- Prevents silent overwriting
- Flags the conflict
- Requests authorized review

---

# Failed Synchronization Handling

Examples:

- Invalid data
- Permission changes
- Deleted records
- Server errors

The user receives a clear explanation and suggested action.

---

# Reliability Principle

A weak internet connection should slow synchronization, not stop farm operations.
