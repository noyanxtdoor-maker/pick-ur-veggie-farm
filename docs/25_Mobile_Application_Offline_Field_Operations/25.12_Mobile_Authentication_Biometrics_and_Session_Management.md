# Mobile Authentication, Biometrics and Session Management

## Purpose

Authentication must balance convenience, security, and real-world farm usability.

---

# Primary Login Method

Version 1 uses:

- Username
- Password

Future options may include:

- One-time passwords (OTP)
- Additional identity verification methods

---

# Biometric Authentication

Supported features:

- Fingerprint
- Face recognition

Biometrics are used to unlock an existing authorized session.

They do not replace account ownership verification.

---

# Session Security

The system supports:

- Automatic session timeout
- Application lock after inactivity
- Re-authentication for sensitive actions
- Secure token management

---

# Sensitive Actions

Examples requiring additional confirmation:

- Viewing financial information
- Approving payroll changes
- Changing security settings
- Accessing confidential records

---

# Multi-Device Sessions

Users may use multiple trusted devices depending on company policy.

The system records:

- Device identity
- Login time
- Last activity

---

# Suspicious Activity Detection

Examples:

- Repeated failed passwords
- Unknown device login attempts
- Unusual access behavior

The system may:

- Send alerts
- Require additional verification
- Temporarily restrict access

---

# Security and Usability Principle

A secure system that is difficult to use will be ignored.

A convenient system without security will become a risk.

PickUrVeggie ERP V3 must achieve both.
