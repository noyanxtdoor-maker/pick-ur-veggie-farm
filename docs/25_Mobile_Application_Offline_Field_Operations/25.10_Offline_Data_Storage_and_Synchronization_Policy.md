# Offline Data Storage and Synchronization Policy

## Purpose

The mobile application must operate without internet while preventing unnecessary company data exposure.

Offline data must be:

- Minimal
- Role-based
- Encrypted
- Temporary

---

# Offline Data Philosophy

Core Rule:

"Store only the information needed to perform current work."

The mobile app is not a copy of the entire ERP database.

---

# Worker Offline Access

Allowed:

- Personal profile
- Assigned tasks
- Current schedules
- Time attendance records
- Personal requests
- SOP instructions
- Pending drafts
- Photos waiting for upload

---

# Supervisor Offline Access

Additional access:

- Team schedules
- Assigned work areas
- Pending approvals
- Team operational records

---

# Restricted Offline Data

The following should not be permanently stored on personal devices:

- Full accounting records
- Complete payroll information
- Other employees' salaries
- Customer financial history
- Supplier confidential pricing
- Full audit logs
- Administrative configuration

---

# Data Expiration

The application automatically removes:

- Old completed tasks
- Expired temporary data
- Successfully synchronized files
- Old cached information

---

# Logout Protection

When a user logs out:

- Authentication tokens are removed
- Encrypted local data is cleared
- Offline access is disabled

---

# Remote Device Revocation

When a device loses trust:

- Synchronization is blocked
- New login is required
- Local company data becomes inaccessible

---

# Final Principle

Offline capability exists to help employees work anywhere.

It must never become a method of copying the entire company's information.
