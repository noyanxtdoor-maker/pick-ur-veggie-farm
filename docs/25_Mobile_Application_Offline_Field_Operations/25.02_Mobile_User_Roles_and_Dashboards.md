# Mobile User Roles and Dashboards

## Purpose

Different users require different information.

A worker should not see the same complex dashboard as the owner.

---

# Farm Worker Dashboard

Primary goal:

Complete daily work quickly.

Displays:

- Today's tasks
- Time-in and time-out button
- Assigned production zones
- Pending work
- Notifications
- Codex quick help button

Example:

Good morning Juan.

Today's Tasks:

☐ Harvest Lettuce Zone A

☐ Apply Fertilizer to Tunnel B

☐ Clean Irrigation Filter

---

# Operator Dashboard

Primary goal:

Manage daily operations.

Displays:

- Team progress
- Production status
- Inventory alerts
- Equipment alerts
- Pending approvals

---

# Supervisor Dashboard

Primary goal:

Control workforce and production quality.

Displays:

- Worker attendance
- Task completion rates
- Production records
- Problem reports
- Maintenance requests

---

# Manager Dashboard

Primary goal:

Monitor performance.

Displays:

- Farm productivity
- Labor efficiency
- Inventory trends
- Production schedules
- Department reports

---

# Owner Dashboard

Primary goal:

Business intelligence.

Displays:

- Codex daily briefing
- Revenue
- Profitability
- Cash position
- Major farm alerts
- Strategic recommendations

---

# Dashboard Customization

Users may customize:

- Favorite shortcuts
- Preferred language
- Notification preferences
- Widget arrangement

---

# Security Principle

Dashboard information follows user permissions.

Codex follows the same permission rules.

A user only sees information appropriate to their role.
