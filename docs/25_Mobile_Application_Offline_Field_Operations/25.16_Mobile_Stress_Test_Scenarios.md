# Mobile Stress Test Scenarios

## Purpose

Before deployment, the mobile application must be tested against real farm conditions, human mistakes, and security risks.

---

# Scenario 1: No Internet During Harvest

Problem:

A worker harvests 100 kg of lettuce without internet.

Expected behavior:

- Harvest is recorded locally
- Data enters the sync queue
- The worker continues operating normally
- The record synchronizes later

---

# Scenario 2: Lost Personal Phone

Problem:

A worker loses a personal smartphone.

Expected behavior:

- Administrator revokes device trust
- Active sessions are terminated
- Offline company data becomes inaccessible

---

# Scenario 3: Worker Forgets to Time Out

Problem:

Employee leaves without pressing time out.

Expected behavior:

- Attendance warning generated
- Worker receives reminder
- Supervisor can review and correct with audit history

---

# Scenario 4: Duplicate Offline Records

Problem:

Two workers accidentally record the same harvest.

Expected behavior:

- Duplicate detection identifies possible conflict
- Records are flagged for review
- No silent data deletion occurs

---

# Scenario 5: Unauthorized Access Attempt

Problem:

A worker attempts to open financial reports.

Expected behavior:

- Access is denied
- Security event is recorded
- User permissions remain enforced

---

# Scenario 6: Phone Storage Is Full

Problem:

A worker tries to capture a crop image but the device has no available storage.

Expected behavior:

- The application warns the user
- Existing upload queues are checked
- The worker receives guidance to free space

---

# Scenario 7: App Update During Farm Operations

Problem:

A new mobile version is released while workers are actively using the application.

Expected behavior:

- Existing work is not lost
- Offline records remain protected
- Synchronization continues after update

---

# Scenario 8: Employee Leaves the Company

Problem:

A former worker still has the app installed.

Expected behavior:

- Account is disabled
- Device access is revoked
- Offline company information becomes inaccessible

---

# Final Mobile Principle

The mobile application is the worker's digital tool.

It must remain:

- Fast
- Reliable
- Secure
- Simple
- Offline-capable

The best farm application is one that workers trust and use every day.
