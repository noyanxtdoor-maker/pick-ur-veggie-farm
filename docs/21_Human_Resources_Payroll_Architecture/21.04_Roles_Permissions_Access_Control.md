# Roles & Permissions Access Control

The ERP follows Role-Based Access Control (RBAC).

Each user only sees information required for their work.

---

## Primary Roles

### Developer

System maintenance and technical administration.

Cannot access private employee data unless granted by company policy.

---

### Owner / Co-Owner

Highest business authority.

Access to:

- Finance
- Reports
- Payroll approvals
- Strategic information

---

### Admin

Manages daily operations.

Access depends on permissions assigned.

---

### Operator

Manages field activities.

Examples:

- Crop activities
- Inventory movements
- Worker assignments

---

### Employee

Limited access:

- Personal dashboard
- Attendance
- Assigned tasks
- Personal requests
- Payslips

---

## Permission Categories

- View
- Create
- Edit
- Approve
- Delete
- Export

---

## Zero Trust Principle

A higher role does not automatically mean unlimited access.

Permissions can be restricted individually.
