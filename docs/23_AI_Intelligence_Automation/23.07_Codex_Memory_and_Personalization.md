# Codex Memory and Personalization

## Purpose

Codex can remember user preferences to create a more personalized experience.

---

## Personal Preferences

Examples:

A manager prefers:

- Daily reports at 7 AM
- Detailed analytics
- English language

A worker prefers:

- Cebuano instructions
- Simple task lists
- Visual guides

---

## Learning User Behavior

Codex may learn:

- Frequently used reports
- Common questions
- Favorite dashboard layouts
- Preferred communication style

---

## Memory Restrictions

Codex does not change:

- Accounting records
- Payroll information
- Inventory quantities
- Business approvals

Memory is only used to improve user experience.

---

## Company vs Personal Memory

Company Memory:

- SOPs
- Farm procedures
- Equipment instructions
- Production standards

---

Personal Memory:

- User preferences
- Language choices
- Notification settings

---

## Privacy Control

Users may:

- View stored preferences
- Modify preferences
- Reset personal Codex settings
