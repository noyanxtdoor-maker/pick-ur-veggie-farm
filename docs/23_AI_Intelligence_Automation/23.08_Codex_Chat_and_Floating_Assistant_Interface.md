# Codex Chat and Floating Assistant Interface

## Purpose

Codex must be available anywhere inside the ERP.

Users should not need to leave their current screen to ask for assistance.

---

## Floating Codex Button

A persistent Codex icon appears throughout the application.

Example:

🐾 Codex Farm Companion

Location:

- Desktop: Bottom-right corner
- Tablet landscape mode: Lower corner with large touch target

---

## Chat Interface Features

The Codex window supports:

- Text conversation
- Quick action buttons
- Suggested questions
- ERP data explanations
- Task recommendations
- Future voice interaction

---

## Context Awareness

Codex understands the current ERP screen.

Example:

User is viewing:

Inventory Module

Question:

"Why is this item low?"

Codex understands the question refers to the selected inventory item.

---

## Quick Action Examples

Inventory:

"Create purchase request"

---

Calendar:

"Show today's tasks"

---

Finance:

"Explain this month's profit change"

---

HR:

"Show attendance issues"

---

## Future Voice Assistant

Voice interaction is planned for future versions.

Example:

"Codex, record today's eggplant harvest."

Codex converts the request into a draft transaction for user approval.

---

## Design Philosophy

Codex should feel like a farm companion walking beside the user, not a separate complicated software feature.
