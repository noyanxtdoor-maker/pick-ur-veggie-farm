# PickUrVeggie ERP V3 AI Development Constitution

## Rule 1 --- Documentation is the Source of Truth

The /docs directory contains the approved architecture. Code must follow
the documentation.

## Rule 2 --- Never Rewrite Working Systems

Changes must be targeted, modular, and backward compatible.

## Rule 3 --- Architecture Before Coding

Business Workflow → UI/UX → Stress Testing → Database → Backend →
Frontend → Testing → Deployment

## Rule 4 --- Agricultural ERP Principles

Purchase → Inventory Asset Consumption → Production Cost Transfer →
Movement Only Spoilage → Loss Sale → Revenue + Inventory Reduction +
COGS

## Rule 5 --- Offline First

The system must operate without internet and synchronize when connection
returns.

## Rule 6 --- Tablet First

Designed for 10--12 inch landscape tablets with large buttons and
minimal typing.

## Rule 7 --- Multi-User Privacy

Every user has a private workspace. Operational data follows role
permissions.

## Rule 8 --- Full Audit Trail

Critical actions must record user, timestamp, old value, new value, and
reason.
