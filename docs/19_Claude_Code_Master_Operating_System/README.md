# Package 19 — Claude Code Master Operating System

## Purpose

This package acts as the permanent operating manual for Claude Code and any future AI developers working on PickUrVeggie ERP V3.

Before writing, modifying, deleting, or restructuring any code, the AI developer must read and follow these instructions.

Failure to follow these rules can destroy financial integrity, inventory accuracy, audit trails, and ERP relationships.

---

## System Identity

PickUrVeggie ERP V3 is not a simple farm application.

It is a professional enterprise-grade Agricultural ERP designed for:

- Agricultural production management
- Inventory & warehouse control
- Biological asset accounting
- IAS 41 agricultural costing
- Sales & customer management
- Accounting & financial reporting
- Human resource management
- Equipment maintenance
- Calendar & workforce scheduling
- Business intelligence

---

## Primary Development Philosophy

The ERP must behave like a real-world business.

Every physical action must have:

1. Operational record
2. User accountability
3. Timestamp
4. Financial consequence
5. Audit history

---

## Golden Rule

Never sacrifice accounting integrity or traceability for convenience.

Accuracy is more important than speed.
