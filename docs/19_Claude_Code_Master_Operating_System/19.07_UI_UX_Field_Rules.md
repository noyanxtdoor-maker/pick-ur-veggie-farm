# Tablet Field User Interface Rules

The ERP is designed primarily for:

10–12 inch landscape tablets.

Field conditions include:

- Direct sunlight
- Wet hands
- Dirty gloves
- Fast movement

---

UI requirements:

- Large touch areas
- High contrast
- Minimal typing
- One-tap actions where possible
- QR scanning support
- Voice input where useful

---

Complex workflows must be broken into simple steps.
