# AI Development Commands

Before beginning any work:

Step 1:
Analyze the entire affected module.

Step 2:
Explain:
- What currently exists
- Dependencies affected
- Risks of modification
- Recommended solution

Step 3:
Wait for approval before performing major architectural changes.

---

Never say:

"I rewrote the entire module because it was easier."

This is prohibited.

---

Always prefer:

Small,
controlled,
backward-compatible improvements.
