# Inventory & Accounting Protection

Inventory is the foundation of financial accuracy.

Every inventory movement must have a reason:

Purchase:
Inventory increase.

Consumption:
Inventory decrease + production cost increase.

Transfer:
Location change only.

Spoilage:
Inventory decrease + loss recognition.

Sale:
Inventory decrease + COGS calculation.

---

The system must always answer:

What was moved?
How much?
When?
Where?
By whom?
Why?
What was the financial impact?
