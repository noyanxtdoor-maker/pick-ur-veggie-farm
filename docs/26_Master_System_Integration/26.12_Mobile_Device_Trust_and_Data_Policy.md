# Mobile Device Trust and Data Policy

## Purpose

Employees may use personal devices to access PickUrVeggie ERP V3.

The system must protect company information without invading employee privacy.

---

# BYOD Principle

Bring Your Own Device (BYOD) is supported.

The employee owns:

- Personal photos
- Personal applications
- Personal files

The company controls:

- ERP application access
- Company data inside the app
- Device trust status

---

# Device Registration

Every device records:

- Device ID
- User
- Operating system
- App version
- Registration date
- Last activity
- Security status

---

# Device Trust Levels

Trusted:

- Normal access allowed.

Restricted:

- Limited access.
- Additional verification may be required.

Revoked:

- No ERP access.
- Company data removed according to policy.

---

# Mobile Security Requirements

The application should support:

- Secure authentication
- Session expiration
- Data encryption
- Secure communication
- Device verification

---

# Local Data Protection

Offline data should be:

- Encrypted
- Minimal
- Role-based
- Temporary

The app should never store:

- Complete company database
- All payroll records
- Full financial reports
- Security credentials

---

# Employee Exit Process

When an employee leaves:

- User account is disabled
- Device trust is revoked
- Company data access ends
- Audit records remain

---

# Lost Device Procedure

If a phone is lost:

- Device is marked as revoked
- Future access is blocked
- Company information is protected
- Security event is logged

---

# Privacy Boundary

The ERP does not monitor:

- Personal messages
- Personal photos
- Personal applications
- Personal browsing

The system only manages business data within the ERP.

---

# Final Mobile Security Principle

A personal phone can become a trusted business tool without becoming company property.

Security must protect the company while respecting the employee's personal privacy.
